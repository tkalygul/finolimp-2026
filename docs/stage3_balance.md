# Этап 3: мост баланса

Запуск после этапов 1 и 2, из корня проекта:

```text
python -m src.balance --clean interim/clean --matching interim/reconciliation
python -m unittest discover -s tests -p test_stage3_balance.py
```

Этап подключен к reconcile.py сразу после сопоставления. CSV сохраняются
в interim/reconciliation, Excel добавляет листы «Мост баланса» и «Сверка по субагентам».

## Выходные файлы

- balance_bridge.csv: по каждому субагенту и месяцу начальные/конечные
  остатки, подписанные причины движения разницы, необъясненный остаток и статус.
- balance_contributions.csv: вклад каждой группы сопоставления в конкретном
  месяце. Исходные строки группы находятся в match_components.csv.
- agreement_balances.csv: начальные/конечные депозиты каждого договора.
- subagent_summary.csv: сводка для Excel; неизвестные месяцы явно учитываются,
  абсолютная сумма остатка показана отдельно, чтобы взаимное погашение не скрывало проблемы.

## Формула

Разница = долг 1С + депозит ETM.

Разница на начало + вклады операций + необъясненный остаток = разница на конец.

Для операций 1С вклад равен debt_delta, для ETM — минус долг из компонентов
(то есть исходная депозитная сумма amount_kgs). Реестр не добавляется к формуле.
Проводки в разных месяцах дают отдельные вклады в месяцы каждого источника.

Начальный депозит первого наблюдаемого месяца договора выводится из
balance_after первой транзакции минус amount_kgs этой транзакции. В последующих
месяцах переносится последний наблюдаемый остаток. В месяцы без транзакций
баланс сохраняется; если выгрузка неполная, обнаружить все пропуски без внешнего
остатка невозможно. До первой транзакции договора его баланс неизвестен.
Если хотя бы один известный договор еще не наблюдался, общий баланс субагента
за тот месяц также неизвестен. Полнота перечня договоров предполагается по выгрузке.

## Статусы и ограничения

- reconciled: числовой мост сходится с допуском 0.02 сома.
- unexplained_residual: остатки источников не объясняются найденными компонентами.
- missing_act: нет акта 1С; сальдо и разница неизвестны, а не равны нулю.
- unknown_etm_balance: нет достаточных данных о депозитах.

check_1c и check_etm показывают внутренние разрывы учета каждого источника.
component_gap показывает обороты, не покрытые компонентами этапа 2.
act_carryover_gap отдельно показывает разрыв переноса сальдо между месяцами.
Сам мост не приписывает начальную разницу текущим операциям и не скрывает
разрыв между соседними актами.

Причина ambiguous может объяснять сумму, но оставаться неустановленной.
cause_review_groups показывает число таких групп и других проверок даже при
нулевом вкладе. Статус reconciled не означает отсутствие ошибок и не разрешает
автоматическую корректировку. Подтверждение виновника и действие бухгалтера —
следующие этапы проекта.

## Разложение необъясненного остатка

Остаток = component_gap - check_1c - check_etm. Поля residual_uncovered_turnover,
residual_internal_1c и residual_internal_etm хранят эти три подписанных компонента;
residual_decomposition_check проверяет их сумму. Это пояснение существующего
остатка, не дополнительные денежные операции. Сдвиги периодов уже входят в
вклады групп и повторно не прибавляются. Неизвестные значения остаются пустыми.
В Excel эти компоненты показаны на листе «Мост баланса».
Сумма модулей месячных необъясненных остатков не является долгом или убытком.
