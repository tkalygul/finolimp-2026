# Этап 6: действия бухгалтера

Полный запуск `python reconcile.py --data data_2_final --out out/report` формирует
листы «Действия бухгалтера» и «Детали действий» в итоговом Excel.
Отдельный запуск отчета: `python -m src.report interim report/reconciliation_report.xlsx`.
Также сохраняются `interim/p5/accountant_actions.csv` и `accountant_action_details.csv`.

Одна строка на субагента содержит последнюю разницу балансов, предложения ETM/1С
со знаком, вопросы для выяснения, ссылки на группы, сценарий после подтверждения.
Последнее сальдо не суммируется по месяцам. Неизвестные балансы остаются пустыми.

Для ошибки суммы ETM и пропущенной операции, поддержанной 1С и реестром,
предложение изменения депозита ETM = нормализованная сумма ETM − сумма 1С.
У отсутствующей операции ETM движение равно нулю. Для продажи 1С после отмены
предложение изменения долга 1С = нормализованная сумма ETM − сумма 1С.
Плюс увеличивает депозит ETM или долг 1С; минус уменьшает.
Разница в сценарии = последняя разница + предложение ETM + предложение 1С.

Финансовые гипотезы требуют подтверждения документов, полноты выгрузок и сборов.
Подтвержденные суммы сейчас равны нулю: инструмент не подтверждает и не проводит
корректировки автоматически. Ожидаемая разница является условным сценарием.

Повторы, различия периодов, ошибки разбора реестра, частичные войды и связанные
аномалии (кроме информационных) блокируют предложение и требуют выяснения.
Ошибки реестра требуют исправления исходной записи и проверки переноса в ETM.
Группа учитывается один раз; суммы аномалий не добавляются к корректировкам.
Повторные ID групп и строки моста отклоняются.
Начальные разницы, неизвестные балансы и необъясненные остатки выводятся явно.
Детали содержат документ 1С, транзакции ETM, код, причину, уверенность и действие.

## Проверка сценария после предложений

scenario_absolute_change = abs(expected_difference_after_proposals) - abs(closing_difference).
Положительное изменение более 0,02 сома означает увеличение общей разницы:
scenario_assessment получает «Увеличивается», scenario_warning объясняет необходимость
проверки остальных расхождений и истории проводок. Строка подсвечивается в Excel.
Исправление отдельной операции может убрать взаимную компенсацию ошибок; знак
предложения автоматически не переворачивается. При неизвестном балансе оценка
«Неизвестно», числовое изменение остается пустым.
