# P5 — Типы ошибок и аномалии

Код: `src/classify_errors.py`, тесты: `tests/test_classify_errors.py`.
Запуск отдельно: `python -m src.classify_errors` (после шагов P2 и P3), в пайплайне — Шаг 3 в `reconcile.py`.

## Как решаем, чья ошибка

Каждую операцию сводим по ключу **субагент + билет (10 цифр) + группа** (продажа или возврат).
Сервисный сбор из 1С прибавляем к продаже, войд из ETM и реестра гасит выкуп.

| Что есть | Правило | Виновник |
| :--- | :--- | :--- |
| 1С, ETM, реестр | два совпадают, третий нет → виноват третий | бот / агент / 1С |
| 1С, ETM, реестр | все три разные | неясно, ручная проверка |
| 1С + ETM (операция субагента, реестра нет) | ETM — первичная система | 1С (средняя уверенность) |
| ETM (+ реестр), нет 1С | нет акта за месяц → `1c_act_missing`, иначе `1c_not_posted` | 1С |
| 1С + реестр, нет ETM | бот не исполнил | бот |
| только реестр | бот не исполнил или опечатка в билете | бот (низкая уверенность) |
| только 1С | проводка без операции | 1С |

Войды: если в ETM выкуп + войд дают ноль, в 1С ничего быть не должно. В реестре после войда остаётся
сервисный сбор — это **не ошибка** (`ok_void_fee`). Если в реестре войд, а в ETM выкуп не отменён — ошибка бота.

Для ошибки суммы есть уточнение `issue`: `duplicate` (вдвое больше), `half`, `wrong_sign`, `parse_error`,
`round_typo` (круглая разница — опечатка), `fx_rate` (курс/округление), `other`.

## Оплаты

Оплаты 1С и ETM сопоставляем по **субагенту + сумме + дате (±5 дней)**, номер п/п — только приоритет:
номера ЦБ-С повторяются у разных субагентов, а в ETM номер есть лишь у половины оплат.

* Нет в ETM → `etm_payment_not_credited` (бот).
* Лишнее зачисление той же суммы в течение 7 дней → `etm_double_credit` (бот).
* Нет в 1С → `1c_act_missing` или `1c_payment_not_posted` (1С).

## Аномалии (`p5_anomalies.csv`)

| Тип | Виновник | Что это |
| :--- | :--- | :--- |
| `etm_duplicate_op` | бот | та же операция по тем же билетам с той же суммой повторно |
| `etm_double_credit` | бот | двойное зачисление оплаты |
| `etm_wrong_sign` | бот | выкуп с плюсом, возврат с минусом |
| `etm_balance_chain_break` | бот (низкая) | остаток после операции не сходится; часть — порядок внутри дня |
| `registry_duplicate_row`, `registry_parse_problem`, `registry_pax_mismatch` | агент | дубли и брак строк реестра |
| `1c_act_missing` | 1С | у субагента есть операции в ETM, а акта за месяц нет |
| `1c_saldo_carryover` | 1С | сальдо на начало ≠ сальдо на конец прошлого месяца |
| `1c_saldo_transfer_suspect` | 1С | одинаковый разрыв сальдо у разных субагентов — похоже, сальдо перенесли не тому |
| `corporate_as_subagent` | 1С | корпоративный клиент из справочника встречается в ETM/1С |

**Частые сбои:** субагент или сотрудник реестра, у которого доля ошибок выше среднего на 2σ
и ошибок не меньше 5 (`frequent_failures` в сводках).
