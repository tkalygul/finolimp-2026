# FinOlimp 2026: сверка расчетов Kyrgyz Concept

Инструмент сопоставляет акты 1С, депозитные транзакции ETM и реестр агентов.
Он формирует мост баланса, список расхождений, предложения действий бухгалтера
и модель очередности проверки. Ручные правки входных данных не нужны.

## Установка на Windows

Проверенная среда: Python 3.12, точные версии библиотек в requirements-lock.txt.
В PowerShell из папки проекта:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-lock.txt
.\.venv\Scripts\python.exe -m pytest -q
```

Виртуальное окружение активировать не обязательно. requirements.txt подключает
тот же файл точных версий. NumPy реализует модели, sklearn/LightGBM/SHAP не требуются.

## Входные файлы

В одной папке должны находиться acts.csv, etm.csv и ровно один registry*.csv.
Схемы колонок описаны в src/schema.py. Для полного запуска используется UTF-8 CSV
с запятой как разделителем. Отдельный загрузчик реестра также поддерживает Windows-1251.
Сохраняйте исходные названия колонок и номера билетов как текст.
reference/corporate_clients.csv отделяет корпоративных клиентов от субагентов.

## Полный запуск

```powershell
.\.venv\Scripts\python.exe -X utf8 reconcile.py --data data_2_final --out out/report
```

Откройте out/report/reconciliation_report.xlsx. Последний успешный запуск указан
в out/report/latest_run.json. Каждый запуск хранится отдельно:

```text
out/report/
  reconciliation_report.xlsx
  latest_run.json
  runs/<UTC-время-ID>/
    reconciliation_report.xlsx
    run_manifest.json
    run.log
    interim/
      clean/                 очищенные выгрузки и аудит строк
      registry.parquet       разобранный реестр
      reconciliation/        группы, компоненты, мост баланса
      p5/                    классификация, аномалии, действия
      ml/                    модель, признаки, метрики и рейтинги
```

Папка результата должна находиться вне папки входных данных. Прошлые запуски
не удаляются и не используются как входы. При ошибке прежний успешный отчет
сохраняется, а новый запуск оставляет журнал и доступную диагностику.

## Новая ежемесячная выгрузка

1. Создайте отдельную папку, например data_2026_08, с тремя исходными CSV.
2. Используйте те же схемы, валюты/курсы и правила формирования выгрузок.
3. Запустите команду с --data data_2026_08 --out out/2026_08.
4. Проверьте листы действий, необъясненные остатки и качество входных данных.

Для отдельного месяца формируется сверка. Честная временная проверка ML требует
минимум двух месяцев и достаточно размеченных примеров обоих бинарных классов.
При нехватке истории отчет продолжает формироваться, статус модели unavailable
и причина показаны на листе «Качество модели». Для отключения обучения:

```powershell
.\.venv\Scripts\python.exe -X utf8 reconcile.py --data data_2026_08 --out out/2026_08 --skip-ml
```

Для обучения предпочтительна накопленная выгрузка с полной историей за несколько
месяцев. Инструмент не склеивает месячные выгрузки автоматически.

## Как читать отчет

| Лист | Назначение |
| --- | --- |
| Действия бухгалтера | Одна строка на субагента: предложения ETM/1С со знаком, вопросы и ожидаемая разница после подтверждения |
| Детали действий | Основания действий, документы, транзакции и ссылки на группы |
| Мост баланса | Начальная разница, подписанные вклады операций, конечная разница и необъясненный остаток |
| Расхождения по билетам / Оплаты с ошибкой | Детализация сумм и предполагаемых источников ошибок |
| Аномалии | Повторы, войды, ошибки данных и концентрация ошибок сотрудников |
| Качество модели | Разметка, временная выборка, метрики, базовое сравнение и ограничения |
| Риски транзакций | Оценки приоритета проверки исходных строк без увеличения числа из-за билетов |
| Приоритет субагентов / сотрудников | Очередь проверки, объем операций и оценки риска |
| Проблемные строки / Дубли реестра | Исходные номера строк и причины проверки |

1С отражает долг положительным, ETM отражает депозит. Согласованные остатки
противоположны по знаку. Разница = сальдо 1С + баланс ETM.
Плюс предложения ETM увеличивает депозит, плюс предложения 1С увеличивает долг.
Неизвестный баланс остается пустым. Нельзя складывать месячные сальдо как обороты.

Финансовые исправления требуют подтверждения первичных документов, полноты
выгрузок и сборов. Программа не выполняет проводки. Суммы риска/аномалий не
являются утвержденными убытками и могут описывать одни и те же операции.

## Модель и независимая разметка

По умолчанию label_basis=rule_proxy: модель воспроизводит гипотезы правил,
а метрики не доказывают точность выявления реальных ошибок. unclear исключается
из обучения бинарной модели. Вероятности не откалиброваны независимо.
Класс без обучающих примеров отмечается как неподдерживаемый.

Проверенную разметку можно передать через --verified-labels labels.csv.
Колонки: match_id,is_error,error_owner,is_verified. Детали в docs/stage7_ml.md.
Обучение использует только подтвержденные строки. Последний месяц отложен,
группы через границу периодов исключены, сохраненная модель не дообучается на test.

## Проверка воспроизводимости

run_manifest.json содержит SHA256 входов/кода/результатов, версии пакетов,
seed, параметры и статус. Проверка целостности и сравнение двух запусков:

```powershell
.\.venv\Scripts\python.exe verify_run.py "out/report/runs/<ID первого запуска>"
.\.venv\Scripts\python.exe verify_run.py "out/report/runs/<ID первого запуска>" --against "out/report/runs/<ID второго запуска>"
```

Сравниваются CSV/JSON результатов. XLSX может отличаться временем упаковки ZIP,
поэтому байтовое равенство Excel не является проверкой равенства его таблиц.

## Если запуск остановился

| Сообщение | Что сделать |
| --- | --- |
| Нет файла / несколько registry*.csv | Проверить папку --data и оставить один реестр |
| Нет обязательной колонки | Восстановить схему выгрузки, указанную в сообщении |
| Отклонены финансовые строки | Открыть interim/clean/data_quality_issues.csv нового запуска, исправить выгрузку в источнике |
| Нет модуля | Установить requirements-lock.txt в используемое окружение |
| Нет доступа к файлу | Закрыть Excel, проверить права и наличие свободного места |
| Модель unavailable | Добавить историю/разметку или использовать отчет без модели |

Журнал: out/<папка результата>/runs/<ID>/run.log. Код завершения 0 означает
готовый отчет, 1 означает остановку. Неполный результат не подменяет успешный.
